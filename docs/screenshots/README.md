# Screenshot Capture Guide for RUNWAY

To provide evaluators and recruiters with quick visual previews, capture the following 6 screenshots from your browser and place them in this folder with exact filenames:

| Filename | Route / Screen | Viewport Width | Instructions |
| :--- | :--- | :--- | :--- |
| `landing.png` | `/` | 1440px (Desktop) | Capture hero section showing the ₹10,000 value proposition, consequence chain preview, and navigation. |
| `today.png` | `/app` | 1440px (Desktop) | Capture the Today Cockpit showing daily allowance hero, stat tiles (wallet, forecast, risk, health), and 30-day runway chart. |
| `decision-lab.png` | `/app/lab` | 1440px (Desktop) | Capture Decision Lab with 1–2 decisions staged in the basket, showing the live ripple impact panel and verdict banner. |
| `plan.png` | `/app/plan` | 1440px (Desktop) | Capture the Commitments & Plan page showing tabs for income, commitments, subscriptions, and savings goal progress cards. |
| `insights.png` | `/app/insights` | 1440px (Desktop) | Capture the Insights screen showing category spending distribution, daily pacing analysis, and the 6-pillar financial health audit. |
| `mobile.png` | `/app` | 390px (Mobile) | Capture Today Cockpit on mobile showing the top header, allowance hero card, quick actions, and bottom navigation bar. |

### Capture Tips
- Use clean dummy test data generated during your walkthrough (e.g. ₹10,000 cycle, a couple of realistic expenses and commitments).
- Ensure PNG format with 2x retina or 1x standard resolution.
- Keep file size reasonable (< 500 KB per image) using tools like TinyPNG if needed.
